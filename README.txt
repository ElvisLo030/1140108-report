# 海上教堂 360° 全景導覽
## 41211147 智慧科技期末作業

這是一個使用 Marzipano 工具生成的 360° 互動式網頁應用程式，提供海上教堂的虛擬導覽體驗。

## 專案特點

- 提供高品質的 360° 全景圖片瀏覽
- 支援多個場景之間的無縫切換
- 包含互動式熱點標記
- 響應式設計，支援各種設備瀏覽

## 場景介紹

本專案包含以下場景：
1. 海上教堂1
2. 海上教堂2
3. 海上教堂3
4. 海上教堂4

## 技術規格

- 使用 Marzipano 全景圖片查看器
- 支援多層級圖片分辨率（256px 到 2048px）
- 提供完整的互動控制介面
- 支援全螢幕瀏覽模式

## 如何使用

1. **本地開發**
   - 由於瀏覽器安全限制，不建議直接開啟 `file://` 連結
   - 請使用本地網頁伺服器來運行專案
   - 主要應用程式檔案位於 `app-files/index.html`

2. **部署說明**
   - 將 `app-files` 資料夾的內容上傳至網頁主機即可
   - 支援任何標準的網頁主機服務

## 專案結構

```
app-files/
├── data.js        # 場景配置和資料
├── index.html     # 主要HTML文件
├── index.js       # 主要JavaScript邏輯
├── style.css      # 樣式表
├── img/           # 介面圖示
├── tiles/         # 全景圖片檔案
└── vendor/        # 第三方依賴庫
```

## 自定義開發

您可以通過編輯以下檔案來自定義應用程序：
- `index.html`: 修改頁面結構
- `style.css`: 自定義視覺風格
- `data.js`: 更新場景資料和配置
- `index.js`: 調整互動行為

## 使用的函式庫

- Marzipano.js - 360° 媒體查看器引擎
- Bowser - 瀏覽器偵測
- Screenfull.js - 全螢幕功能支援
